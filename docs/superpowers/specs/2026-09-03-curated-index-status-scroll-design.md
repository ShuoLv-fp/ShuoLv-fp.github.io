# Curated Index 独立滚动与联系状态设计

## 目标

只调整导师档案页左侧 `CURATED INDEX`：桌面端使其与右侧导师详情独立滚动，并在每位导师条目中直接显示 `YOUR NOTES` 内保存的联系状态。

## 交互设计

- 桌面端的导师页占据当前可用视口高度。左侧索引形成独立纵向滚动区域，右侧详情内容保持页面原有滚动方式；浏览右侧长内容时，左侧索引位置不随之移动。
- 左侧标题和筛选框保持在索引顶部，只有导师列表滚动。
- 每个导师条目保留头像、姓名、学校和匹配分数，并新增文字状态徽标：`Discovered`、`Shortlisted` 或 `Contacted`。
- 状态徽标直接读取导师记录的 `status` 字段，与右侧 `YOUR NOTES` 使用同一数据源。用户在右侧修改状态后，重新渲染左侧条目，使徽标立即同步。
- 若状态缺失或不在支持列表中，徽标显示 `Discovered`，避免空白状态。

## 响应式行为

- 宽屏继续采用左右两栏；索引的高度限制和纵向滚动只在宽屏生效。
- 窄屏继续沿用现有横向导师卡片列表，不强制固定高度或纵向滚动，以免挤压详情内容。

## 视觉规则

- 状态使用紧凑的文字徽标，不引入图标或新配色体系。
- 三种状态沿用现有页面语义色：发现阶段为中性灰蓝，候选阶段为强调青色，已联系为成功绿色。
- 匹配分数与状态徽标放在同一右侧信息列中，保证导师名称区域仍可正常省略显示。

## 数据与错误处理

- 不增加或迁移字段，不修改任何导师、邮件或申请数据。
- 使用现有 `row.status` 和 `markDirty` 同步机制；状态更新失败时仍沿用现有未同步提示和重试流程。

## 验证

- 静态界面测试确认索引具有独立滚动样式。
- 静态界面测试确认导师条目渲染联系状态徽标。
- 测试确认右侧状态选择器触发导师列表重新渲染。
- 运行完整测试与部署预检，确保其他视图和同步功能未受影响。
